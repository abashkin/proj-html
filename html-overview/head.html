<head> Tag

The <head> tag contains meta-information about the HTML document, such as the title, character set, styles, and scripts. This information is not displayed on the page itself but is essential for the proper functioning of the document.

Example:

<head>
    <meta charset="UTF-8">
    <title>My Web Page</title>
</head>
