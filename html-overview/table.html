<table> Tag

The <table> tag is used to create tables in HTML. Tables are structured using rows (<tr>) and cells (<td>). Headings within a table are defined using the <th> tag.

Example:

<table>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
        <tr>
            <td>Alice</td>
            <td>25</td>
        </tr>
    </table>
